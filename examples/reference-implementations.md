# Reference Implementations

This document provides real-world examples of how organizations have implemented network connectivity capabilities.

---

## Example 1: Global Bank - Site-to-Site Connectivity

### Organization Profile
- Global tier-1 bank
- 500+ locations worldwide
- 24/7 trading operations

### ABB Implemented
- Site-to-Site Connectivity Service
- Business Continuity Connectivity

### SBB Selection
**Primary**: Cisco SD-WAN over MPLS + DIA  
**Rationale**: Needed application-aware routing with failover

### Results
- Provisioning time: 60 days → 21 days
- Availability: 99.7% → 99.92%
- Cost per site: Reduced 35%

## Example 2: Regional Bank - User-to-Application Connectivity

### Organization Profile
- Regional bank (US Northeast)
- 5,000 employees
- 50% remote workforce

### ABB Implemented
- User-to-Application Connectivity Service

### SBB Selection
**Primary**: Zscaler Private Access (ZPA)  
**Rationale**: Zero-trust architecture, cloud-native

### Results
- VPN infrastructure retired (cost savings)
- User experience improved (app response time)
- Security posture strengthened (zero-trust)
